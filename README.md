# Bölüm Takip

Tracks master's applications from country to university to programme for non-EU/EEA applicants: the deadline that actually binds you, costs in several currencies, and whether you meet the entry requirements.

## Problem
Programme pages mix EU and non-EU application rounds, fees and prerequisites. Following them by hand in a spreadsheet makes it easy to miss the deadline that matters.

## Result
- Deployed as a login-protected personal tool.
- 240 automated checks.
- Its model now powers the multi-user product Burs Takip: https://furkanakduman.vercel.app/work/burs-takip

## Status
Live, personal use.
